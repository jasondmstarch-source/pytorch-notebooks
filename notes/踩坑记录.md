# 踩坑记录

> 学 PyTorch 时真正卡住过的地方。记下来，下次不踩；也证明我真的动手跑过。

## 1. `NameError: name 'torch' is not defined`

**现象**：Jupyter 里后面的格子一运行就报这个错。
**原因**：Jupyter 所有格子共用一个「内核」，变量/导入要**先跑过的格子才存在**。
直接跳着运行、或重启过内核后没重跑第一个 `import torch` 的格子，后面的格子就不认识 `torch`。
**解决**：菜单 `Kernel` → `Restart Kernel and Run All Cells`，从头按顺序跑一遍。
**教训**：改完代码养成「从顶部重跑」的习惯；格子左边的 `[3]` 是执行顺序，不是位置顺序。

## 2. `optimizer.zero_grad()` 忘了写 —— 模型学不动但不报错

**现象**：loss 不降反乱跳，程序也不报错，很难查。
**原因**：PyTorch 默认**累积梯度**，不手动清零，上一步的梯度会叠到这一步。
**解决**：每个训练循环里，`loss.backward()` 之前一定要先 `optimizer.zero_grad()`。
**教训**：这是 PyTorch 最坑的地方——**静默失败**。背下来：`zero_grad → forward → loss → backward → step`。

## 3. 形状不匹配（shape mismatch）

**现象**：各种 `RuntimeError`，大多跟矩阵维度有关。
**解决**：报错先看 `.shape`，别急着怀疑算法。深度学习的错 90% 出在形状对不上。
**关键区分**：`x * y` 是逐元素乘，`x @ y` 是矩阵乘，两回事。
