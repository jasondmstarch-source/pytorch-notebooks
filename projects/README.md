# projects/

未来的**竞赛作品 / 课程设计 / 复现实验**都放这里。

每个项目单独一个子文件夹，结构建议：

```
projects/
└── 我的项目名/
    ├── README.md      # 这个项目干嘛的、用了什么、怎么跑（一行命令最好）
    ├── main.py / *.ipynb
    └── 结果图/         # 效果图、对比图（小图可入库，大文件走外链）
```

## 已经盯上的方向（光电 + AI 结合点）

- 图像去噪 / 超分辨（计算成像常用）
- 相位恢复（无镜头成像、差分相位对比）
- 「湾区光谷」光电设计赛 概念设计组 的作品

> 规则：README 写好再算「完成」。一张效果图 + 清晰的运行步骤，比代码长更重要。
