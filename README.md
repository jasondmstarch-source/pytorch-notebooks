## 这个仓库是什么

不是教程，是**我自己的学习轨迹**：从跑通第一个张量开始，到复现实验、做竞赛作品，每一步的代码和踩坑都留在这里。
目的是——将来保研复试 / 竞赛答辩时，能直接打开给人看：「我会写代码、能复现实验、有持续积累」。

```

```

## 怎么跑起来

本机环境在 `D:\pytorch-env`（独立虚拟环境，CPU 版 PyTorch，无显卡也能跑）。
双击桌面「启动 Jupyter (PyTorch)」快捷方式，浏览器打开后点 `.ipynb` 文件，按 `Shift+Enter` 逐格运行。
